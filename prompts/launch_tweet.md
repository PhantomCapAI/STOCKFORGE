# Launch Tweet — Style Guide

The announcement that ships with a launch (composed by `Promoter`, or by the LLM
forge in `launch_tweet`).

## Structure
```
$SYMBOL is live — <one-line hook tying to the TICKER narrative>.
<what it is / why now, <=1 line>
CA: <address>   (added post-deploy)
Not affiliated with <TICKER>. NFA.
```

## Rules
- **<= 270 characters.**
- Always lead with `$SYMBOL`.
- One concrete hook — the actual reason the ticker is hot, not "to the moon".
- Always end with the affiliation disclaimer + `NFA`.
- No return promises, no financial advice, no fake partnerships.
- Clean footprint: don't tag the real company's official handle as if endorsed.

## Example
```
$SILNV is live — riding NVDA's compute-demand tape into the next print.
Attention in, fees out — revenue funds the agent that runs it.
Not affiliated with NVDA. NFA.
```
